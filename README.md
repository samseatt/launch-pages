# Launch Pages

Public landing pages for the September 11, 2026 founding publication
of Neuverse Commons, Tiers, xMed, and Guten.

## Sites

| Folder | Public address | Purpose |
|---|---|---|
| `neuverse/` | https://neuverse.space | Neuverse Commons founding message, organs, and charters |
| `tiers/` | https://tiers.ai | Tiers founding message, architecture, and charters |
| `xmed/` | https://xmed.ai | xMed, the first organ under Neuverse Commons |
| `guten/` | https://www.guten.ink | Publication catalogue and book introductions |

Guten initially introduces two works:

- **The Path of Many Arrows** — why we need better civilizational
  design; planned as three printed volumes.
- **The Living Stack** — a companion field guide exploring how we
  might begin building it without losing the humans it is meant to serve.

## Publication stages

1. **Preparation:** establish placeholder pages, hosting, domains, and HTTPS.
2. **September 11, 2026:** publish founder's messages and selected founding material.
3. **Ongoing:** add approved charters, reading editions, and supporting resources.

## Hosting

Each site folder is deployed as a separate Cloudflare Pages project.
Changes committed to the configured production branch publish automatically.

Cloudflare provides the initial hosting. The Guten application is the
intended long-term publishing platform. Public URLs should be preserved
when hosting changes.

## Content boundaries

This repository contains website publication files.

Authoritative book manuscripts remain in their existing source locations.
Manuscript drafts, private notes, credentials, and database exports do not
belong in this repository.

Dedicated initiative and book repositories maintain their respective
founding documents and development or publication workflows.
